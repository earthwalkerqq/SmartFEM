# Генерация КЭ-сетки с использованием Gmsh

Этот модуль использует **Gmsh CLI** для построения конечной элементной (КЭ) сетки из CAD-модели и сохраняет результаты в виде файлов с узлами и элементами.

## Возможности

- Импорт CAD-моделей (STEP/STP файлы)
- Настройка глобального размера сетки (`clmin`, `clmax`)
- Генерация 2D сетки (треугольные элементы)
- Экспорт сетки в формате Gmsh (`.msh`)
- Выгрузка списка узлов и элементов в текстовый файл в формате `node.txt`
- Визуализация сетки в GUI Gmsh (опционально)

---

## Использование

### Базовое использование (без GUI):
```bash
cd HyperMesh
./generate_mesh.sh ../../materials/data-sample/52.stp 0.1 1.0
```

### С визуализацией в GUI Gmsh:
```bash
cd HyperMesh
./generate_mesh.sh ../../materials/data-sample/52.stp 0.1 1.0 gui
```

### Параметры:
1. `STEP_FILE` - путь к STEP/STP файлу (обязательный)
2. `clmin` - минимальный размер элемента сетки (по умолчанию: 0.1)
3. `clmax` - максимальный размер элемента сетки (по умолчанию: 1.0)
4. `gui` - показать GUI Gmsh после генерации (опционально: `gui` или `1`)

### Результаты:
- `../build/HyperMesh.msh` - сетка в формате Gmsh
- `../build/node.txt` - сетка в формате для FEM-модуля
