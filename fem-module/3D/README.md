# 3D Modal (Vibrational) Analysis Module

Модуль для вычисления собственных частот и форм колебаний конструкций.

## Назначение

Вычисление собственных частот и форм колебаний для 2D/3D конструкций методом конечных элементов.

## Функциональность

- Построение глобальных матриц жесткости `K` и масс `M`
- Решение обобщенной задачи собственных значений: (K - ω² M) φ = 0
- Метод: inverse power iteration с CG solver
- Поддержка граничных условий (закрепления по U и V)
- Цветной вывод в консоль (зеленый для успеха, красный для ошибок, желтый для предупреждений)

## Сборка

```bash
cd fem-module/3D
make
```

Собирает исполняемый файл `../build/3d`

## Использование

```bash
./build/3d <node.txt> <numModes> <density> <thickness>
```

Параметры:
- `node.txt` - файл с сеткой (узлы и элементы)
- `numModes` - количество мод для вычисления (по умолчанию: 3)
- `density` - плотность материала в кг/м³ (по умолчанию: 7850 для стали)
- `thickness` - толщина в метрах (по умолчанию: 1.0)

## Результаты

Результаты сохраняются в файл `Modal_result.txt` в рабочей директории и содержат:
- Собственные значения (lambda = ω²)
- Собственные частоты (omega в rad/s и частота в Hz)
- Формы колебаний (смещения узлов для каждой моды)

## Граничные условия

Граничные условия задаются в файле `node.txt` в формате:
```
<num_nodes>
x1 y1 z1 u_flag1 v_flag1 load_flag1
x2 y2 z2 u_flag2 v_flag2 load_flag2
...
<num_elements>
node1 node2 node3
...
```

где:
- `u_flag = 0` означает закрепление по U (X направление)
- `v_flag = 0` означает закрепление по V (Y направление)
- `load_flag = 100` означает наличие нагрузки на узел

Для модального анализа требуется хотя бы одно закрепление (по U или V, или по обеим осям).

## Зависимости

- Стандартная библиотека C (math, stdlib, stdio)
