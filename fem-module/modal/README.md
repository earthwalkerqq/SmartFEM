# Modal (Vibrational) Analysis Module

Назначение: вычисление собственных частот и форм колебаний (2D сначала, с расширением до 3D).

План:
- Построение и хранение глобальных матриц `K` (жёсткости) и `M` (масс)
- Решение обобщённой задачи собственных значений: (K - ω^2 M) φ = 0
- Методы: степенной метод, inverse/power shift, (позже) Lanczos/ARPACK
- Интеграция с существующим FEM-модулем (reuse геометрии/сборки K)

Сборка:
- `make` — собирает бинарь `../build/modal`
- `make clean` — очистка

Дальше добавим чтение сетки и сборку K/M.
