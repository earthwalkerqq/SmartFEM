# SmartFEM GUI - Qt приложение для задания параметров

Графический интерфейс для задания всех параметров расчета SmartFEM.

## Возможности

- Выбор STEP файла через диалог
- Задание параметров генерации сетки (clmin, clmax)
- Задание параметров материала (E, ν, ρ, h)
- Выбор типа анализа (статический FEM или модальный)
- Задание количества мод для модального анализа
- Запуск расчета с отображением вывода
- Автоматическая генерация сетки и запуск FEM/модального анализа

## Использование

1. **Выберите STEP файл** - нажмите "Обзор..." рядом с полем "STEP файл"
2. **Задайте параметры сетки** - минимальный и максимальный размер элементов
3. **Задайте параметры материала**:
   - E - модуль упругости (МПа)
   - ν - коэффициент Пуассона
   - ρ - плотность (кг/м³)
   - h - толщина (м)
4. **Выберите тип анализа**:
   - Статический FEM анализ
   - Модальный анализ (колебания)
5. **Для модального анализа** - укажите количество мод
6. **Нажмите "Запустить расчет"**

## Результаты

- Вывод отображается в текстовом поле внизу окна
- Результаты FEM сохраняются в `build/result.txt`
- Результаты модального анализа выводятся в консоль
